Why I Built This Blog

I decided to build my blog the old-fashioned way: plain HTML files, a stylesheet, and a little JavaScript. No frameworks, no build step, no dependencies.

Sometimes the simplest approach is the best one. You can host this anywhere that serves static files — GitHub Pages, Netlify, Vercel, or even a plain web server.

How it works

All posts live in js/posts.js as JavaScript data. The homepage lists them automatically, and each post has its own page at post.html?slug=your-post-slug.

To publish a new post, just add an entry to the POSTS array — no other changes needed.
