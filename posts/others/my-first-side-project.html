My First Side Project: A Habit Tracker

This month I built a small habit tracker web app to practice my JavaScript skills. No framework — just vanilla JS and localStorage.

What it does

You can add habits, check them off each day, and see a weekly streak view. Data persists in the browser.

What I learned

Working on a real project taught me more than any tutorial. I ran into CORS issues, state management headaches, and a bug that took two hours to find.

Side projects are the best way to learn — highly recommend giving it a try.
